# 2025 수원연화장 부고록

2025년 수원연화장 부고 내역을 디지털로 기록하고 검색할 수 있는 웹 애플리케이션입니다.

## 주요 기능
- **데이터 검색**: 성함, 유가족, 장지 등으로 부고 내역을 빠르게 검색할 수 있습니다.
- **상세 보기**: 각 부고 내역을 클릭하여 빈소, 발인 일시, 장지 등 상세 정보를 확인할 수 있습니다.
- **반응형 디자인**: 모바일과 데스크탑 모두에서 최적화된 화면을 제공합니다.
- **다크 모드 지원**: 사용자 시스템 설정에 따른 자동 다크 모드를 지원합니다.

## 기술 스택
- HTML5 / Vanilla CSS3 / JavaScript (ES6+)
- Google Fonts (Inter, Noto Sans KR)
